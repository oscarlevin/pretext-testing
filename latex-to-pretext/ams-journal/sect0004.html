Lemma 1.1

Let \(f, g\in A(X)\) and let \(E\), \(F\) be cozero sets in \(X\).

  1. If \(f\) is \(E\)-regular and \(F\subseteq E\), then \(f\) is \(F\)-regular.

  2. If \(f\) is \(E\)-regular and \(F\)-regular, then \(f\) is \(E\cup F\)-regular.

  3. If \(f(x)\ge c{\gt}0\) for all \(x\in E\), then \(f\) is \(E\)-regular.

The following is an example of a proof.

Set \(j(\nu )=\max (I\backslash a(\nu ))-1\). Then we have
